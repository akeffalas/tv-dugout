Rules I'd suggest

  • Changing age range or level only changes which videos are marked Recommended. It never adds or removes videos by itself.
  • "New" marks library videos added since the child was set up. The skill chip counts them so you can find them.
  • Unchecking a video hides it from the child but keeps its progress. Checking it again brings the progress back.
  • Every skill with videos in the library is listed, so you can add a skill the wizard skipped.
